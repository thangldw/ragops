# RAGOps v2.4.0

## New

- **`ragops init --from LOGS --output DIR`**: build a first scenario and report from your own JSON/JSONL RAG logs in about a second. `--source-format langfuse|openai|anthropic` imports those platforms' exports ([guide](../quickstart-init.md)).
- **`ragops compare --format explorer`**: one self-contained HTML report with filters, search, side-by-side baseline/candidate answers and highlighted unsupported words.
- **Pull-request comment** from the GitHub Action (`comment: true`), **`semantic_grounding`** plug-in evaluator with calibration, and **release tooling** (`scripts/release_tools.py`).
- CI now covers Python 3.11–3.15 on Linux plus macOS, and type-checks the whole package with mypy. Coverage gate is 91%.

## Fixes

Property-based and mutation tests found and fixed many crashes: wrongly typed or non-UTF-8 input to the scenario, response, policy, pilot, dataset, evidence, trace-graph, OpenTelemetry and replay-bundle loaders raised `TypeError`, `KeyError`, `AttributeError` or `UnicodeDecodeError` instead of a contract error.

## Read before relying on grounding scores

Independent public benchmarks changed our claims. On HaluEval QA (10,000 pairs) `lexical_groundedness` scores 92.9% and `strict_grounding` 91.0%, so the earlier 93% vs 72% figure from the maintainer-labeled benchmark does not generalize. On RAGTruth long answers `strict_grounding` is near chance (AUROC 0.53 to 0.58) and lexical grounding is weak (0.68 to 0.76). Off-the-shelf NLI models did not beat lexical grounding either. Use `strict_grounding` for short factual answers, and calibrate any scorer on your own labeled responses with `ragops calibrate`. See [HaluEval](../case-study-halueval.md), [RAGTruth](../case-study-ragtruth.md) and [semantic evaluator](../semantic-evaluator.md).

## Compatibility

No breaking changes. `lexical_groundedness`, contracts, exit codes and decisions are unchanged; new features are opt-in. Existing 2.3.x baselines remain valid. Adapters for Langfuse/OpenAI/Anthropic follow documented export shapes and have not been run against a live account export.
