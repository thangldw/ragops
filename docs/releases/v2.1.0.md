# RAGOps v2.1.0

RAGOps 2.1.0 adds CI integration and evaluator hardening without changing the offline evaluation contract.

- Adds a composite GitHub Action (`action.yml`) that runs `ragops gate-v2`, writes the canonical decision plus JUnit, SARIF and GitHub Summary renderings, and fails only on `BLOCK`.
- Lexical groundedness now splits Japanese/Chinese character runs into bigrams and NFC-normalizes text (so composed and decomposed Vietnamese match). It remains a lexical-overlap baseline, not a semantic judge; the README now says so.
- Adds API HTTP, baseline-manifest, usage and Markdown-reporter tests and a CI coverage gate (`fail_under = 82`, currently ~85%).
- Moves the argument parser into `cli_parser.py`; `ragops.cli.build_parser` is unchanged.

## Compatibility

- Python 3.11 or newer; zero required runtime dependencies; core stays offline.
- Existing CLI commands, exit codes, contracts and canonical `PASS`, `WARN`, `BLOCK` decisions are unchanged.
- Groundedness scores for Japanese/Chinese text can differ from 2.0.2 because of the new tokenization. English scores and the synthetic demo (`1.0 -> 0.6`) are unchanged; re-accept baselines for CJK scenarios if their thresholds are tight.
