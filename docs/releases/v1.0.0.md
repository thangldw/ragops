# RAGOps v1.0.0

## English

Complete merged baseline for deterministic and statistical RAG/agent regression gates, portable scenarios, trace adapters, evaluator policies, provenance diagnosis, evidence bundles, CLI/API surfaces and two reusable read-only GitHub workflows.

Baseline đầy đủ cho regression gate xác định/thống kê của RAG/agent, scenario portable, trace adapter, evaluator policy, chẩn đoán provenance, evidence bundle, CLI/API và hai reusable GitHub workflow chỉ đọc.
