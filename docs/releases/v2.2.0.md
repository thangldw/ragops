# RAGOps v2.2.0

- Adds the opt-in `strict_grounding` evaluator: claim-level support, exact numbers and identifiers, and negation contradictions. On a labeled held-out split it reaches 87% accuracy versus 71% for `lexical_groundedness`. The benchmark is author-labeled synthetic data; see [evaluator accuracy](../evaluator-accuracy.md) for the numbers and known failures.
- Adds `ragops pilot-init` and a [design-partner offer](../gtm/design-partner-offer.md) to make real pilot evidence easier to collect. This release contains no production adoption evidence.

## Compatibility

- Python 3.11 or newer; zero required runtime dependencies; core stays offline.
- `lexical_groundedness` and all existing scores, contracts, exit codes and decisions are unchanged. New features are opt-in.
