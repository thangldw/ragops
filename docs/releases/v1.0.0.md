# RAGOps v1.0.0

## English

Complete merged baseline for deterministic and statistical RAG/agent regression gates, portable scenarios, trace adapters, evaluator policies, provenance diagnosis, evidence bundles and local CLI/API surfaces. Repository-owned GitHub Actions are intentionally excluded.

## Tiếng Việt

Baseline đầy đủ cho regression gate xác định/thống kê của RAG/agent, scenario portable, trace adapter, evaluator policy, chẩn đoán provenance, evidence bundle và CLI/API cục bộ. GitHub Actions thuộc repo được chủ động loại bỏ.

## 日本語

決定的・統計的な RAG／agent 回帰ゲート、ポータブルシナリオ、trace adapter、evaluator policy、来歴診断、証拠 bundle、ローカル CLI/API を含む統合版です。リポジトリ所有の GitHub Actions は意図的に除外しています。
